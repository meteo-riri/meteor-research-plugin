## Standard Opening Phrases

**For major revisions requiring new data:**
```
We thank Reviewer N for this important comment. We agree that {concern}.
[AUTHOR INPUT REQUIRED: describe planned additional experiment or analysis]
We plan to address this in a revised manuscript.
Revision status: [MANUSCRIPT CHANGE PENDING]
```

**For clarification requests (no new experiment needed):**
```
We thank Reviewer N for pointing this out. To clarify: {explanation}
We have revised the text to make this clearer. [LINE NUMBERS TO BE ADDED]
Revision status: [MANUSCRIPT CHANGE PENDING]
```

**For minor text corrections:**
```
Thank you for this suggestion. We have corrected/revised {item} accordingly.
[LINE NUMBERS TO BE ADDED]
Revision status: [MANUSCRIPT CHANGE PENDING]
```

**For disagreement with a reviewer comment:**
```
We respectfully disagree with this interpretation. {Scientific reasoning}
We believe the current presentation is appropriate because {reason}.
However, to address the reviewer's concern, we have {optional minor addition}.
Revision status: [MANUSCRIPT CHANGE PENDING]
```

## Citation Format Within Response

```
[PROPOSED CITATION — AUTHOR APPROVAL REQUIRED]
{Authors}. "{Title}." {Journal} {Year}. DOI: {DOI}
Evidence inspected: abstract
Support level: {directly supports claim | methodological precedent | general context}
```

Maximum 3 unsolicited new citations per response section.
